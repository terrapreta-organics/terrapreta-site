# terrapreta.ca

Static site built with Eleventy 3, edited with Decap CMS at `/admin`. Field report style.

## Build

    npm install
    npm run build        # preview: DRAFT posts and hidden placeholders render, pages send noindex
    npm run build:prod   # production: drops DRAFT posts and hidden placeholders, pages are indexable
    npm start            # local dev server

Output goes to `_site/`. `netlify.toml` already sets the build command and publish folder.

## Where things live

- `src/pages/*.md`: every page (home, reclamation, restoration, agriculture, contact, blog page, 404). All copy and photos are in the front matter as `hero` + `blocks`.
- `src/blog/posts/*.md`: blog posts. `draft: true` keeps a post off the blog page and out of the sitemap, adds noindex and a DRAFT bar, and drops it entirely from `build:prod`.
- `src/_data/site.json`: menu, footer, email, GA4 ID, canonical origin, and `noindex` (emergency hide for the live site). Preview builds are noindex either way.
- `src/_data/seo.json`: search keywords, default share image, and the structured data facts (address, hours, map pin, social profiles).
- `src/images/`: photos (Decap uploads go here too).
- `src/_includes/blocks/`: one template per section type (text, photo, duo, rows, list, why, faq, hidden, paths, cta, form).
- `src/admin/config.yml`: Decap config, generated by `scripts/build-decap-config.js` (`npm run cms-config`). Edit the script, not the YAML.

## Search and launch

Production (`npm run build:prod`, which is what Netlify runs on main) is indexable while `"noindex"` is false in `src/_data/site.json`. Deploy previews run `npm run build` and send `noindex`. Set `"noindex": true` only to hide the live site again.

- Contact form: set the Formspree endpoint in `src/_includes/blocks/form.njk` (search for TODO).
- Check the `[Pending Lee OK]`, `[Placeholder ...]` and `[Rest waits on Derek]` notes are resolved or removed.
- `src/_redirects`: `/about` points at home until an About page exists. Older product, solution, calculator, and evidence URLs redirect to agriculture or reclamation.
